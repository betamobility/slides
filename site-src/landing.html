The deck is one file.

Beta Slides is Beta Mobility's presentation system: a build of bento/slides that carries the Beta design system, exports editable PowerPoint, and is written and revised by Claude. One HTML file is the deck, the viewer and the editor. It opens from disk, needs no account, and saves itself.

Branded from the design system

Cream, charcoal, Playfair Display, Inter and DM Mono ride inside every deck as Bento theme, fonts and layouts. Re-layout by role, restyle from one place.

Editable PowerPoint

Export writes real text boxes, shapes, tables and charts, and reports the elements that had to degrade to an image.

Written by Claude

The beta-slides plugin extends the upstream skill with Beta's design rules, data refresh with an as-of date, and PPTX export.
